# 👟 CR FORWARD - Catálogo Oficial 2026

Bienvenido al repositorio oficial de **CR FORWARD**. Esta es una aplicación web diseñada para visualizar los catálogos de la nueva temporada de forma fluida, segura y profesional.

## 🚀 Características Principales

- **Experiencia Nativa:** Navegación optimizada para dispositivos móviles (iPhone/Android) y escritorio (PC/Mac).
- **Gestos Inteligentes:** Cierre de catálogos mediante gestos laterales (swipe) y compatibilidad total con botones de retroceso de **Mouse Gamer**.
- **Seguridad de Contenido:** 
  - Bloqueo de inspección de código y clic derecho.
  - Protección contra impresión no autorizada.
  - Renderizado mediante Canvas para evitar descargas directas de imágenes.
- **Diseño Responsivo:** Interfaz adaptable que prioriza la información relevante en pantallas pequeñas.

## 🛠️ Tecnologías Utilizadas

*   **HTML5 & CSS3:** Estructura y diseño con efectos de desenfoque (glassmorphism).
*   **JavaScript (Vanilla):** Lógica de gestos y manejo de historial del navegador.
*   **PDF.js:** Motor de renderizado de alta fidelidad para documentos PDF.

## 📱 Cómo usarlo

1. Selecciona una categoría (Deportivas, Hombre, Mujer o Niños).
2. Para volver al menú principal desde un catálogo:
   - **En Móvil:** Desliza el dedo desde el borde izquierdo hacia la derecha.
   - **En PC:** Usa el botón de retroceso de tu mouse o el botón "← Volver" en pantalla.
   - **En Laptop:** Usa el gesto de retroceso en el trackpad.
